# Утилита фильтрации содержимого файлов

## Описание

Данная утилита предназначена для фильтрации содержимого файлов, содержащих перемешанные данные различных типов: целые числа, вещественные числа и строки. Утилита считывает строки из указанных файлов и записывает их в отдельные выходные файлы в зависимости от типа данных.

## Установка

Для использования утилиты необходимо иметь установленную Java (версия 21 или выше).
В проекте используется библиотека `commons-cli` версии `1.9.0`, которая упрощает обработку аргументов командной строки.

Скомпилируйте проект при помощи Gradle Wrapper и получите исполняемый JAR-файл при помощи команды:
```shell
.\gradlew jar
```
## Запуск

Утилита запускается из командной строки с указанием входных файлов и опциональных параметров. Пример команды:

```bash
java -jar file-filter-service-1.0-SNAPSHOT.jar -o some/path -p result_ -f in1.txt in2.txt -a
```
Где `in1.txt` и `in2.txt` - файлы со входными данными, которые **расположены на одном уровне** с исполняемым `.jar` файлом.

Пример входных данных:
```text
Lorem ipsum dolor sit amet
45
Пример
3.1415
consectetur adipiscing
-0.001
тестовое задание
100500
```

#### Параметры командной строки

Программа поддерживает следующие параметры командной строки:

| Короткий флаг | Длинный флаг    | Аргумент | Описание                                                          |
|---------------|-----------------|----------|-------------------------------------------------------------------|
| `-o`          | `--output`      | Да       | Задает путь для сохранения результатов. Пример: `-o /path/to/dir`. |
| `-p`          | `--prefix`      | Да       | Задает префикс имен выходных файлов. Пример: `-p result_`.        |
| `-s`          | `--short`       | Нет      | Включает вывод краткой статистики.                                |
| `-f`          | `--full`        | Нет      | Включает вывод полной статистики.                                 |
| `-a`          | `--append`      | Нет      | Включает запись результатов в уже существующие файлы.             |

> Если в параметре `-o` указать путь, начинающийся с `/` (например, `/output`), директория будет создана в корне файловой системы. 
> Это требует наличия соответствующих прав доступа. Если путь не начинается с `/`, директория будет создана относительно текущей рабочей директории.
